# Runs flow

## Entry

Open `/runs` for the configured local repository.

## Ready

Show an explicit planned state for discovery, drafting and review. Explain that runs are unavailable and that local browsing and checks remain available. Offer no run action or fabricated execution history.

## Empty and failure states

A successful empty load identifies its source. Failed loads show an error and unavailable values. An unknown interaction ID returns not found. Unimplemented adapters remain planned.

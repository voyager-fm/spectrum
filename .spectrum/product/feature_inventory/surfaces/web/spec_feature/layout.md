# Spec feature layout

## Regions

Repository navigation, page heading and load errors precede the reader. The specification tree sits beside the content, with the feature marked and its category expanded. A breadcrumb links to the category. The content shows the feature ID and description, a property grid with interaction count, interactions with a document, lifecycle mix and related UI region, the interaction table with filters, and links to the previous and next feature.

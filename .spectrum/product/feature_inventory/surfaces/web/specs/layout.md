# Specs layout

## Regions

Repository navigation, page heading and load errors precede the reader. The specification tree sits beside the content on wide screens and collapses behind a toggle under 1024px. The content shows counts for categories, features, interactions, interactions with a document, interactions declared implementing and interactions with findings; the filter toolbar with active filter chips; the interaction table grouped by category; the categories and features table with descriptions; and the documents table with kind tabs. Category and feature names in the tree link to their pages. For a connected repository, a **Graph view** link sits beside the revision line.

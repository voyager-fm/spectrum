# Spec document layout

## Regions

Repository navigation, page heading and load errors precede the reader. On wide screens the reader shows the specification tree, the document body and a rail with the outline, links in both directions and the source location. Under 1280px the rail follows the body; under 1024px the tree collapses behind a toggle.
